# vao.dev portfolio

Interactive developer portfolio built with React 19 and Vite. The application lives in `site/`.

## Run locally

```powershell
cd site
npm install
npm run dev
```

## Commands

| Task | Command |
| --- | --- |
| Local development | `cd site; npm run dev` |
| Production build | `cd site; npm run build` |
| Hosting test | `cd site; npm run test:sites` |

## Working with an AI agent

Before making a change, read:

1. `AGENTS.md`
2. `site/AGENTS.md`
3. `docs/AI_HANDOFF.md`

The project is image-first: the supplied scene images are the visual source of truth. Do not replace, regenerate, crop, or reposition them unless the owner explicitly asks.
